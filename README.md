# The Vault — Mobile App

The premium mobile experience for luxury handbag rentals.

## Tech Stack
- **Framework**: React Native (Expo)
- **Navigation**: React Navigation (Native Stack + Bottom Tabs)
- **Icons**: Lucide React Native
- **Typography**: Playfair Display (Headings), Inter (Body)
- **State Management**: (TBD - planned Redux Toolkit or Zustand)

## Project Structure
- `src/api`: API client and services
- `src/assets`: Local assets (fonts, images)
- `src/components`: Reusable UI components
- `src/constants`: Theme, config, and constants
- `src/navigation`: Navigation configuration
- `src/screens`: Application screens
- `src/store`: State management
- `src/utils`: Helper functions

## Getting Started
1. `npm install`
2. `npx expo start`
